# Foundation Setup

## Goal

Create a small, verifiable foundation for learning and building DevStash with .NET and React.

## Acceptance Criteria

- The repository contains a .NET 10 solution.
- The solution contains an ASP.NET Core API and an xUnit test project.
- The test project references the API project.
- `GET /health` returns a successful healthy response.
- An integration test verifies the health endpoint.
- The React frontend uses Vite and TypeScript.
- Backend restore, build, and tests pass.
- Frontend install and production build pass.
